# Pizza Sales Analysis Dashboard

## Overview

The **Pizza Sales Dashboard** is an interactive Power BI project designed to analyze pizza sales performance across different categories, sizes, and individual products. The dashboard transforms raw sales data into meaningful visual insights to support **sales analysis, inventory planning, and data-driven decision-making**.

## Objectives

* Analyze overall pizza sales performance.
* Identify top-performing and low-performing pizza products.
* Compare sales across pizza categories and sizes.
* Track key sales KPIs such as revenue and average sales.
* Provide interactive filtering for deeper analysis.
* Generate actionable insights for business decision-making.

## Key Features

* Interactive Power BI dashboard
* Sales performance analysis
* Category-wise sales analysis
* Size-wise sales analysis
* Product-level performance analysis
* Top and low-performing product identification
* Dynamic slicers and filters
* KPI cards for quick performance monitoring
* Interactive charts and visualizations

## Data Preparation

The raw dataset was processed using **Power Query** before creating the dashboard.

The data preparation process included:

1. Importing the raw sales dataset.
2. Removing unnecessary columns and records.
3. Handling missing and inconsistent values.
4. Correcting data types.
5. Transforming and structuring the data.
6. Creating calculated fields required for analysis.
7. Loading the cleaned data into the Power BI data model.
